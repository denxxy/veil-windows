# Veil для Windows

Клиент на чистом Python (tkinter): один и тот же протокол, что и у
macOS-приложения — переписка между Windows- и macOS-клиентами через общий
relay работает «из коробки». Также запускается на Linux/macOS, что удобно
для отладки.

## Установка на Windows

1. Установите [Python 3.8+](https://www.python.org/downloads/) (при установке
   отметьте **Add python.exe to PATH**).
2. Скопируйте папку `windows/` на ПК (достаточно файлов `veil_core.py`,
   `veil_client.py`, `requirements.txt`, `run_windows.bat`).
3. Дважды щёлкните `run_windows.bat` — он сам поставит зависимости
   (`cryptography`, `websocket-client`) и запустит клиент.

Зависимости вручную: `pip install -r requirements.txt`.

## Использование

1. При первом запуске — «Создать личность».
2. «Реле…» → добавьте адрес relay (например, `https://relay.example.com`),
   кнопкой «Проверить» убедитесь, что он отвечает.
3. «Мой профиль» → «Скопировать приглашение» → передайте код собеседнику
   (на macOS он вставит его в «Добавить контакт»).
4. «Добавить контакт» — вставьте чужой код приглашения.

Состояние и ключи: `%APPDATA%\Veil\store.json`. «Мой профиль» позволяет
импортировать резервную копию личности, **включая файл, экспортированный
из macOS-клиента** (формат общий), и выгрузить свою.

Транспорт: WebSocket-push (если установлен `websocket-client`) плюс
REST-опрос с джиттером 4–9 с — тот же запасной путь, что в macOS-клиенте.

## Проверка без GUI

```
python veil_core.py --selftest
```
